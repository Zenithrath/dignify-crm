# CRM v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Restyle the CRM to the approved reference (light content, dark collapsible sidebar, orange accent) and build the Work/Content/Calendar/Dashboard tracking flows.

**Architecture:** React + Vite + Tailwind v4 + shadcn (base-mira) unchanged. Theme flips to light via CSS tokens (removing the forced `.dark` class activates light `:root` values already present). New Work/Content/Rotation types + mock hooks follow the existing `useData.ts` pattern. No backend.

**Tech Stack:** React 19, TypeScript, Tailwind v4, GSAP (existing animations), lucide-react icons.

**Spec:** `docs/superpowers/specs/2026-08-26-crm-v2-design.md`

## Global Constraints

- No test runner is installed; every task verifies with `npx vite build` (must pass) and `npx oxlint src` (no new errors).
- UX rules from spec: page title + description + one primary action top-right; visible filters; helpful empty states; badges always text+color; forms label-above-field.
- Sidebar stays dark in both themes; content area is light.
- Class-name sweep must NOT touch the sidebar internals of `Layout.tsx` (they stay white-on-dark).
- Commit after every task.
